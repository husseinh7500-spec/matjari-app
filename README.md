# متجري الذكي - نسخة Windows

## إنشاء ملف EXE من الهاتف عبر GitHub
1. ارفع جميع ملفات هذا المشروع إلى المستودع `matjari-windows` في الفرع `main`.
2. افتح تبويب **Actions** في GitHub.
3. اختر **Build Windows EXE** ثم **Run workflow** إذا لم يبدأ البناء تلقائياً.
4. انتظر حتى تصبح نتيجة التشغيل خضراء.
5. افتح تشغيل workflow ثم انزل إلى **Artifacts** واضغط `Matjari-Windows-Installer` لتنزيل ZIP.
6. فك الضغط على جهاز Windows وشغّل `MatjariSetup.exe`.

## ملاحظات
- بيانات المنتجات والفئات وسعر الصرف تحفظ محلياً في ملف تعريف التطبيق داخل المتصفح المحلي (localStorage).
- النسخ الاحتياطي والاستيراد بصيغة JSON.
- اتصال الإنترنت مطلوب للمكتبات الخارجية وخدمة تحديث سعر السوق.
- هذه نسخة أولية مستقلة عن Android؛ لا تنقل قاعدة بيانات Android تلقائياً. صدّر بيانات Android بصيغة JSON إذا أردت نقلها، ثم استوردها في نسخة Windows بعد تفعيل ذلك الخيار في واجهة النسخ الاحتياطي.
